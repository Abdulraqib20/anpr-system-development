About the ANPR System

An initiative by the Department of Computer Engineering, University of Ilorin.

Project Overview

The University of Ilorin ANPR System represents a cutting-edge solution in vehicle identification and security management. This system combines advanced computer vision techniques with modern web technologies to create a robust, user-friendly platform for automated license plate recognition.

Purpose

Designed to enhance campus security and vehicle monitoring capabilities through automated license plate detection and recognition, providing a scalable solution for traffic management and access control.

Technology Stack

Built using state-of-the-art technologies including YOLOv8 for object detection, Meta's Llama 4 Scout for advanced OCR, Flask for web implementation, and PostgreSQL for robust data management.

Security & Privacy

Implements role-based authentication, secure data storage, and encrypted communications to ensure the integrity and confidentiality of all captured vehicle information.

Performance

Achieves high accuracy in plate detection and recognition across various lighting conditions and vehicle types, with efficient processing and real-time data management capabilities.

Python Flask YOLOv8 PostgreSQL OpenCV TensorFlow Llama 4 Bootstrap

Key Features

Accurate Detection

Utilizes advanced YOLO models for precise license plate localization in images.

Intelligent OCR

Employs state-of-the-art multi-modal AI for reliable character recognition from plate images.

Data Management

Securely stores detection data, including timestamps, plate numbers, and associated images.

User Authentication

Role-based access control for secure system operation and data privacy.

Theme Customization

Personalize the user interface with a variety of selectable visual themes.

Admin Dashboard

Comprehensive admin panel for user management and system oversight.
