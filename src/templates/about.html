Project Overview

The AI-Powered Automatic Number Plate Recognition (ANPR) System is a sophisticated solution leveraging the power of Artificial Intelligence for advanced vehicle identification and security management. Developed as a capstone final-year project at the University of Ilorin, this system integrates Artificial Intelligence and cutting-edge computer vision with modern web technologies to deliver a robust, scalable, and user-friendly platform for automated license plate recognition and vehicle attribute analysis including type and brand detection.

Core Purpose

To significantly enhance campus security, streamline vehicle monitoring, and provide a versatile tool for traffic management and data-driven access control through precise automation.

Technology Backbone

Powered by Python, Flask, YOLOv8 for object detection, Meta's Llama Vision models via Groq API for lightning-fast optical character recognition & car brand detection, OpenCV for image processing, and PostgreSQL for reliable data persistence. The frontend is built with Bootstrap 5 and dynamic JavaScript.

Security & Privacy Focus

Features robust user authentication, role-based access, secure data handling practices, and emphasizes data integrity and privacy in all captured vehicle information.

Performance & Scalability

Engineered for high accuracy in diverse conditions, efficient real-time data processing, and designed with scalability in mind to handle growing datasets and user demands.

Tech Stack Highlights

Python Flask YOLOv8 PostgreSQL OpenCV Groq API Large Vision Models Bootstrap 5 JavaScript

Key Features

Precision Detection

Leverages YOLOv8 for highly accurate license plate and vehicle localization, even in challenging scenes.

Ultra-Fast Llama Vision OCR

Utilizes Groq's LPU Inference Engine with Meta's Llama Vision models for near-instantaneous and reliable character recognition.

Car Brand Identification

Integrates AI-powered car brand detection, adding another layer of vehicle analytics.

Robust Data Management

Securely stores and manages all detection data, including images, timestamps, and recognized details in PostgreSQL.

Secure User Access

Implements comprehensive role-based authentication (Admin/User) for secure operations and data protection.

Dynamic Theming

Offers a rich selection of Bootswatch themes, allowing users to personalize the application's appearance.

Multiple Image Uploads

Supports batch processing of images through both the web UI and command-line interface.

Responsive Interface

A clean, modern, and fully responsive user interface for seamless access across devices.

API Usage Metrics

Admin panel provides insights into Groq API token consumption for monitoring and cost management.
